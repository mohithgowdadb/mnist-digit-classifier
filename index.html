The pipeline

FROM PIXELS
TO PREDICTION.

Four transformations turn a picture of a digit into a single, confident answer. Scroll to walk through each one.

01 — IMAGE
A picture,
nothing more.

It starts as an ordinary image — a digit written by hand, scanned or drawn, no different to the eye than any other photo.

02 — PIXELS
28 × 28
pixel grid.

The image is resized into a 28 by 28 grid — 784 individual squares, each holding one shade of grey.

03 — NEURAL NETWORK
784 input
features.

Every pixel becomes one number the network can read — a value between 0 and 255 describing how dark it is.

04 — PREDICTION
10 output
classes.

The network weighs every feature and settles on one of ten possible digits — the prediction.
